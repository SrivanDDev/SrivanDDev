# Hi, I’m Srivan

I’m a Computer Science student interested in backend engineering, systems programming, and developer tools. I build projects in C++ and Python to understand how software handles requests, processes data, and reports failures.

## Selected projects

### [cpp-http-server](https://github.com/SrivanDDev/cpp-http-server)

An HTTP server built from scratch in C++ using POSIX sockets. It serves static files, exposes a health endpoint, and supports a configurable port and document root. The project includes unit and integration tests and explores request parsing, routing, response serialization, and graceful shutdown.

**Tools:** C++ · POSIX sockets · CMake · CTest

### [Quaestio](https://github.com/SrivanDDev/Quaestio)

A streaming log-analysis toolkit with a Python API and command-line interface. It parses text and NDJSON, supports custom log layouts, filters events, ranks repeated errors, and exports text, JSON, and CSV reports.

**Tools:** Python · CLI tooling · Automated tests · GitHub Actions
